# NoteApp

Упрощённый аналог Milanote для себя: бесконечные доски с карточками, вложенные доски, стрелки, ссылки с превью, списки дел, скетчи (рисунки от руки), картинки и файлы. Всё работает офлайн и хранится в обычных файлах у вас на компьютере.

## Запуск

Нужен [Node.js](https://nodejs.org) (LTS-версия).

- Двойной щелчок по `start.bat` — при первом запуске он сам установит зависимости.
- Или в терминале: `npm install`, затем `npm start`.

Собрать самостоятельный `.exe` (без Node.js): `npm run dist` → файл появится в папке `dist`.

## Где лежат данные

Путь к папке с данными задаётся в файле `datapath.json` в корне программы (в собранной версии — рядом с `.exe`). Если файла нет, программа создаст его при запуске с путём по умолчанию — `Документы\NoteApp`:

```json
{
  "dataPath": "C:\\Users\\Имя\\Documents\\NoteApp"
}
```

Чтобы хранить данные в облаке, впишите путь к папке на облачном диске и перезапустите программу. В JSON обратные слэши удваиваются, либо пишите прямые: `"G:/Мой диск/NoteApp"`. Можно использовать переменные окружения: `"%USERPROFILE%\\OneDrive\\NoteApp"`. Открыть файл можно из меню «Файл → Изменить путь к данным». Чтобы перенести уже созданные доски, скопируйте содержимое старой папки в новую.

Если папка недоступна (например, облачный диск не подключён), программа сообщит об этом и не станет создавать пустые доски в другом месте.

Содержимое папки:
- `boards\` — по одному JSON-файлу на доску;
- `assets\` — картинки, файлы и превью ссылок;
- `backups\` — ежедневная копия досок (хранятся последние 14 дней).

Не открывайте одну и ту же папку в двух копиях программы одновременно (например, на двух компьютерах): последняя сохранённая версия доски перезапишет другую.

## Управление

| Действие | Как |
|---|---|
| Создать карточку | перетащить инструмент с панели слева на холст или щёлкнуть по нему |
| Новая заметка | двойной щелчок по пустому месту или `N` |
| Ссылка / To-do / Доска / Стрелка / Скетч | `L` / `T` / `B` / `A` / `D` |
| Рисовать в скетче | двойной щелчок или `Enter` по скетчу. В редакторе: карандаш `P`, выделение `V` (рамкой или щелчком, затем тянуть / `Delete`), ластик `E`, толщина `[` / `]`, `Ctrl+Z` / `Ctrl+Y`; сохранить — `Ctrl+Enter`, выйти без сохранения — `Esc` |
| Редактировать заметку | двойной щелчок, `Enter` или повторный щелчок по выбранной |
| Закончить редактирование | `Esc`, `Ctrl+Enter` или щелчок мимо |
| Форматирование текста | панель над заметкой: «Стиль», жирный, курсив, списки; правый щелчок внутри заметки открывает меню «Стиль» |
| Стиль абзаца | крупный заголовок `Ctrl+Shift+1`, заголовок `Ctrl+Shift+2`, обычный `Ctrl+Shift+0`, мелкий `Ctrl+Shift+9`, код `Ctrl+Shift+.`, выноска `Ctrl+Shift+6`, цитата `Ctrl+'` (повторное нажатие возвращает обычный текст) |
| Цвет и выделение текста | выделите слова → «Стиль» → «Цвет» / «Выделение» |
| Соединить стрелкой | потянуть за синий кружок справа от карточки |
| Переместить в другую доску | перетащить карточки на значок доски |
| Открыть доску | двойной щелчок; наверх — `Alt+←`, хлебные крошки или боковая кнопка мыши «назад» |
| Двигать холст | колесо мыши, правая/средняя кнопка или `Пробел` + перетаскивание |
| Масштаб | `Ctrl` + колесо, `Ctrl+=` / `Ctrl+-`, сброс `Ctrl+0` |
| Выделение | рамкой по пустому месту, `Shift`/`Ctrl` + щелчок, `Ctrl+A` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Y` |
| Копировать / вырезать / вставить / дублировать | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` / `Ctrl+D` |
| Удалить | `Delete` |
| Цвет заметки, настройки доски, стиль стрелки | правый щелчок по карточке или стрелке |
| Поиск по всем доскам | `Ctrl+F` |
| Вставить из буфера | `Ctrl+V` на холсте: ссылка → карточка-ссылка, картинка → картинка, текст → заметка |
| Перетащить файлы из Проводника | картинки станут картинками, остальное — файлами |

## Структура кода

- `main.js` — главный процесс Electron: окно, сохранение, вложения, загрузка превью ссылок.
- `preload.js` — безопасный мост `window.api` между интерфейсом и главным процессом.
- `src/store.js` — данные досок, сохранение, отмена/повтор.
- `src/format.js` — стили текста в заметках: панель и меню «Стиль».
- `src/sketch.js` — скетч: отрисовка рисунка на карточке и редактор рисования.
- `src/render.js` — отрисовка карточек и стрелок. Новый тип карточки = новая функция `body_<тип>`.
- `src/interact.js` — мышь, клавиатура, вставка, перетаскивание, контекстное меню.
- `src/app.js` — навигация, действия с карточками, поиск, запуск.
